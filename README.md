# Saarthi AI — Your Everyday AI Assistant

Saarthi AI is an Android AI assistant designed to help users with everyday questions and tasks.

## Features
- AI Chat
- Photo Solver
- Hindi and English support
- Writing Assistant
- Notes and Chat History
